A FEW THINGS TO KNOW

开始之前，
你可能想知道。

它会替代 Codex、Claude Code 或我的编辑器吗？+

不会。Control Everything 帮你组织项目与人工事项，查看已接入的工具和会话。你仍在原来的工具里完成开发工作。

现在可以直接给 Agent 派任务吗？+

当前版本不开放 Agent 自动执行或审批。为事项选择负责人只记录分工，不会自动向工具发送指令。

需要安装 Python、Node.js 或 Rust 吗？+

Windows 安装包包含运行环境，无需另装这些工具。安装后启动程序，通过本机浏览器打开工作台即可使用。

手机端和远程控制现在能用吗？+

尚未开放。当前服务仅监听本机。桌面客户端、跨设备浏览器访问与 Android 控制端属于后续规划，页面中的设备画面是概念示意。

数据保存在哪里？+

项目和人工事项保存在本机工作台的数据目录。可使用现有配置、导入和备份能力管理资料；连接外部来源时按对应配置访问。
